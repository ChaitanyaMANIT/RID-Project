# Memory scrapbook photos

Drop 6–8 photos here named exactly:

```
memory-01.jpg
memory-02.jpg
memory-03.jpg
memory-04.jpg
memory-05.jpg
memory-06.jpg
memory-07.jpg
memory-08.jpg
```

Then open `src/data/memories.ts` and replace each `[ADD MEMORY]` with the
caption or tiny story for that photo — that's the handwriting that appears
under the polaroid.

Any of these can be missing; a missing photo renders as a `[ADD PHOTO]` card.
